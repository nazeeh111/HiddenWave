# Source and additions

The retained numerical code, utilities and scene illustrations originate from [computational-imaging/nlos-fk, commit d34d49fed5a86f4ebddf85d461cff6923de5367d](https://github.com/computational-imaging/nlos-fk/tree/d34d49fed5a86f4ebddf85d461cff6923de5367d). The repository accompanies *Wave-based non-line-of-sight imaging using fast f-k migration* by David B. Lindell, Gordon Wetzstein and Matthew O'Toole, SIGGRAPH 2019. These are the research authors; this notice does not assign individual authorship to every implemented method or source line.

The original SOURCE-MANIFEST.json records the 10 MATLAB source/utility files and 22 scene illustrations at that pinned upstream version. Nine of those source files and all scene illustrations remain unchanged. The intentional changes to `cnlos_reconstruction.m` are recorded in docs/SOURCE-AMENDMENTS.json and remain subject to the original academic/noncommercial terms. The original Copyright (c) 2018, Stanford University notice and academic/noncommercial terms remain in [LICENSE](LICENSE).

HiddenWave adds repository identity, documentation, artwork, a forwarding entry point, smoke/numerical checks and an original ideal confocal point example. The existing reconstruction formulas remain; input admission, default crop handling and optional headless/metadata return were added to the retained function. Separately authored documentation, artwork, wrapper, tests and the original ideal-input generator are covered by [LICENSE-branding](LICENSE-branding). Changes inside the retained `cnlos_reconstruction.m` remain under its original academic/noncommercial terms. This notice records provenance and does not change either license.
